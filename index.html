Generalized Delannoy Grids

Builds Delannoy arrays following Edwards & Griffiths, Delannoy Constructions: an array R(m, n) satisfying R(m,n) = R(m−1,n) + R(m,n−1) + R(m−1,n−1), seeded either by Dk(m,0) = C(m+k,k) or by seeds you supply. Transform the result with the paper's horizontal/vertical sum operators, inspect it mod p, or export it.

Generate

Any array built this way that satisfies the recurrence is a Delannoy array (Edwards & Griffiths, Def. 12) — it doesn't need to come from a binomial formula.

up to 250 × 250 — large exact grids take a moment; a modulus stays fast at any size

Exact values use arbitrary-precision integers; a modulus reduces every entry, including intermediate sums, at each step, so it stays exact and fast at any grid size. The page URL updates with your k-mode settings — copy it directly, or use "Copy link to this grid".
