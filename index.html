Generalized Delannoy Grids

Builds the Dk(m, n) table from Edwards & Griffiths, Delannoy Constructions: the top row is always 1, the left column is C(m+k, k), and every interior cell is the sum of the cell above, above-left, and left of it. Set k, choose the grid's row and column count, and optionally reduce every entry modulo μ.

Parameters

up to 250 × 250 — large exact grids take a moment; a modulus stays fast at any size

Exact values use arbitrary-precision integers; a modulus reduces every entry, including intermediate sums, at each step, so it stays exact and fast at any grid size. The page URL updates with your settings — copy it directly, or use "Copy link to this grid", to share an exact configuration.
